## 🎯 Bizning Missiya (Our Mission)

**Rust Uzbekistan (`rust-uz`)** — O‘zbekistonda tizimli dasturlash (systems programming), operatsion tizimlar, xavfsiz taqsimlangan tarmoqlar va yuqori unumdorlikdagi arxitekturani rivojlantirishga bag‘ishlangan rasmiy muhandislik hamjamiyatidir.

Biz yosh muhandis va talabalarni shunchaki yuza dasturchi (*"kod dehqoni"*) emas, apparat (hardware), operatsion tizimlar va kompyuter muhandisligini chuqur tushunadigan chinakam **Kompyuter Muhandislari (Computer Engineers)** etib tarbiyalashni maqsad qilganmiz.

## 💻 `ferris-cli` O‘rnatish (Installation)

Rustacean terminal dasturini istalgan platformada bir zumda o‘rnating:

### Cargo (Universal)
```bash
cargo install ferris-cli
```

### Arch Linux (AUR)
```bash
yay -S ferris-cli
```

### macOS (Homebrew)
```bash
brew install rust-uz/ferris/ferris
```

### Debian / Ubuntu (.deb)
```bash
curl -LO https://ferris.uz/download/ferris-cli-latest-amd64.deb
sudo dpkg -i ferris-cli-latest-amd64.deb
```

## 🔒 Post-Quantum Cryptography & Kriptografik Butunlik

Ferris platformasi Markaziy Osiyoda birinchi bo‘lib **Post-Quantum Cryptography (PQC)** tamoyillarini joriy qildi:
* Har bir xabar va post **BLAKE3 (256-bit)** kriptografik zanjiri (`msg_hash` + `prev_hash`) orqali tekshiriladi.
* Ma’lumotlar yaxlitligi va soxtalashtirilmasligi (tamper-proofing) kvant hisoblash tahdidlari (Grover algoritmi) qarshisida $2^{128}$ xavfsizlik darajasini kafolatlaydi.
